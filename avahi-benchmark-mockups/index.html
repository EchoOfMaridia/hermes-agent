TTT Benchmark Dashboard — Mockups for Avahi

7 pages, self-contained HTML, dark theme, inline SVG charts. Open any page from the nav above.
FOR AVAHI This is the partner-handoff bundle. Every page has a green FOR AVAHI or DESIGN NOTE callout explaining the visualization choice. Read those first — they are the load-bearing comments for the design conversation. The data is mocked to follow the actual rule sets in the four spec docs (General Concepts, Butter-Bench, Drive-Thru-Bench, Open-Vend). The shapes are designed to be data-swappable without restructuring.
